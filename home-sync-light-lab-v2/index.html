WHAT V2 IS TEACHING

Audio thread
Decoding runs in AudioWorklet instead of requestAnimationFrame, so DSP timing is isolated from UI frame rate.
Clock model
SHOW_TIME = RATE × LOCAL_MONOTONIC_TIME + OFFSET.
Discipline
New packets are observations, not commands to hard-jump every frame. Small errors slew; large errors reacquire.
Holdover
When acoustic packets disappear, the local monotonic clock continues the show until packets return.
Transport
This demo uses 4-FSK + CRC. A production system can swap in watermark, LTC, fingerprint, ESP-NOW, or Link without replacing the cue engine.

# NFIR · IKEDA 3D LIVESET

《无需进一步输入 / No Further Input Required》的「池田亮司式」黑白三维音画 liveset。

- 单文件、零依赖、离线可演：raw WebGL 3D + WebAudio 生成电子乐 + NFIR 状态机
- 六视觉状态：GRID → FIELD → DATA → RAIN → RING → BURST
- 四音乐状态（正交于视觉）：SILENT / PULSE / SEQUENCE / DENSITY
- 控制：`START(S)` `NEXT(空格)` `HOLD(H)` `AUTO(A)` `MUSIC(M)` `BPM±` `RESET(R)` `LOG(L)`
- ⚡ 高频闪烁提示
